## 按量付费怎么收费：请求处理费加功能费，按天结算

WAF 3.0 按量付费是后付费模式，先使用再付费，每天结算一次（以 UTC+8 时间为准），结算完进入新的周期，直到退订为止。计费项只有两个：

- **请求处理费**：一个完整小时内的请求费用；
- **功能费**：一个完整小时内使用不同功能产生的费用。

费用以 SeCU 为计量单位。SeCU 是 WAF 3.0 引入的按量付费统一计量单元，国际站口径下 1 SeCU = 0.01 美元；中国站按人民币计价，具体单价以下单页展示为准。官方也明确提示，产品及服务价格可能变动，最终以阿里云账单为准。

两项费用都支持 SeCU 资源包抵扣。所谓“按量资源包”，指的就是这个预付费抵扣包：先把额度买好，出账时优先从资源包里扣。

有一个容易漏算的地方：如果通过云产品接入方式为 ALB 实例开启 WAF 防护，除了 WAF 侧的账单，ALB 侧还会单独结算 ALB WAF 增强版实例费用。做预算时按两笔算。

## SeCU 资源包的抵扣规则：先扣资源包，再扣余额

SeCU 资源包本质上是给按量付费账单预存额度的抵扣包。买完后自动抵扣按量付费实例产生的请求处理费和功能费，官方说明这样搭配可以降低费用成本。

具体抵扣逻辑有四条，都出自官方计费文档：

1. **抵扣顺序**：出账时优先抵扣 SeCU 资源包；
2. **兜底逻辑**：资源包抵扣完或超过有效期后，自动改为抵扣账户余额，所以记得保持账户余额充足；
3. **欠费限制**：资源包只能在账户非欠费的状态下抵扣。欠费期间它帮不上忙，先处理欠费；
4. **用量不够**：资源包不支持直接续费或升级，解决办法是再买一个，或者直接换更大规格。

一条实操建议：第一次买不要囤大规格。资源包一旦投入使用就不能退，先按预估用量买小的，账单跑起来后看消耗速度，不够再叠加。

## 常见问题

**SeCU 资源包抵扣完了怎么办？**
自动改为抵扣账户余额，不需要手动操作。要做的是保持余额充足，欠费状态下资源包无法参与抵扣。

**每天扣了多少钱在哪里看？**
WAF 控制台的账单管理页面可以看到按量付费实例的实际用量和产生的费用，扣费账单在用户中心查看。

**按量付费能直接转成包年包月吗？**
不能直接变更计费方式，需要先退订按量付费实例，再重新开通包年包月实例。退订前记得备份或迁移数据。

**不想用了怎么停止计费？**
在已备份或迁移数据、不影响业务的前提下释放实例，关闭后 T+1 天起不再计费。按量付费按实际用量结算，本身无需续费。

**为什么 ALB 接入会多出一笔费用？**
通过云产品接入方式为 ALB 实例开启 WAF 防护时，WAF 侧照常结算，ALB 侧还会结算 ALB WAF 增强版实例费用，预算里要把这笔算进去。
